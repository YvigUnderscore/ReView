# HDRI library

> Updated: 2026-07-18

*Admin → Contextes de review → 3D & Splat* manages the studio's **HDRI environment
library** used to light 3D and splat reviews.

- Upload `.hdr`/`.exr` environments; a tonemapped preview is generated in the
  browser.
- Reviewers pick an HDRI (and exposure) in the 3D viewer; the choice is persisted
  **per media** so every viewer gets the same lighting.
- Removing an HDRI does not break existing media — they fall back to the default
  environment.
