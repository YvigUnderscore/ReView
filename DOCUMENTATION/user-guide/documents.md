# Documents

> Updated: 2026-07-18

The **Documents** page (`/documents`, sidebar entry) hosts free-form rich-text
documents written inside ReView: briefs, meeting notes, delivery specs…

- Scope: **global** (studio-wide) or attached to a **project**.
- Rich-text editor with headings, lists, links.
- All roles except `CLIENT` can create and edit.

Not to be confused with the **Documentation** page (`/docs`), which renders this
product manual (read-only, versioned with the code).
