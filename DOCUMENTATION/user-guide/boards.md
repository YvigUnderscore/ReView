# Boards

> Updated: 2026-07-18

Each **project** and each **asset** has a 2D board powered by **Excalidraw** — a
free-form canvas for moodboards, references, briefs and sketches.

## Access

- Project board: project page → Board (or shortcut `g` then `b`, or Ctrl+K).
- Asset board: from the asset page.

## Features

- Freehand drawing, shapes, arrows, text, sticky-note style layouts.
- Paste or drag images onto the canvas.
- The board is saved per project/asset and shared by the whole team.
