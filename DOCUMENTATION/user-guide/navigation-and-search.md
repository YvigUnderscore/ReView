# Navigation & search

> Updated: 2026-07-18

## Layout

- **Home** (`/`): personal dashboard — recent activity, items needing your
  attention.
- **Projects** (`/projects`), **Reviews** (`/reviews`): global lists with filters.
- **Sidebar**: hybrid navigation — pinned links, the current project's tree
  (sequences/shots/assets), favorites (star), recent items, Documents and
  Documentation. It can be collapsed.

## Search

- **Permanent search field** in the sidebar.
- **Ctrl/Cmd+K** opens the command palette: multi-entity search (projects,
  sequences, shots, assets, tasks) plus quick navigation entries (kanban/board of
  the current project, documentation). Results respect your project memberships.

## Keyboard shortcuts

- `g` then `p` → Projects; `g` then `k` → current project's kanban; `g` then `b` →
  current project's board.
- `?` opens the shortcut help panel (review modes add their own shortcuts —
  transport, tools…).

## Right-click & bulk actions

Most cards (projects, shots, assets, tasks, versions, media) expose their actions
through the **context menu** (right-click). Lists support **multi-selection** for
bulk operations (move, delete, status…), with per-item RBAC checks server-side.

## Favorites & recents

Star any entity to pin it in the sidebar; recently visited items are listed
automatically.
