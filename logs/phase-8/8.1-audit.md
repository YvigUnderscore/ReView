# Sous-phase 8.1 — Audit du repo v1 & décisions

> Date : 2026-06-19. Document de référence pour la reconstruction ReView 2.0.

## 1. Décision framework backend : **garder Express 5**

| Critère | Express 5 | Fastify | Verdict |
|---------|-----------|---------|---------|
| Maturité du code existant | Déjà en place, Express **5** (moderne) | Réécriture du plumbing | Express |
| Écosystème intégré | `multer`, `socket.io`, `helmet`, `cors` branchés | À re-câbler | Express |
| Goulot d'étranglement réel | I/O MinIO + FFmpeg, pas le HTTP | idem | Neutre |
| Sûreté de typage | TS + **Zod** sur chaque route | TS + schémas natifs | Neutre |
| Coût de bascule | 0 | Élevé, sans gain utilisateur | Express |

**Conclusion :** on garde Express 5. Le typage et la validation viennent de TypeScript + Zod,
indépendamment du framework.

## 3. Changement de modèle majeur : Team → Studio + ProjectMembership

- v1 : multi-tenant par `Team` (quotas, rôles, Discord par équipe).
- v2 : `Studio` **singleton** (une instance = un studio). Rôle RBAC **global** sur `User`
  (ADMIN | SUPERVISOR | ARTIST | CLIENT) + `ProjectMembership` pour le scoping d'accès.
- Conséquence : `checkProjectAccess` se simplifie (admin/superviseur = accès global ;
  artiste/client = via membership ; client = via ShareLink).

## 4. Hiérarchie pipeline (remplace Project > Video/ImageBundle/ThreeDAsset)

```
Studio > Projet > Séquence(opt) > Shot > Task > Version > MediaObject
                > Asset(réutilisable) > Version > MediaObject
```
`Comment` est **unifié** : il référence un `MediaObject` (au lieu de 3 FK séparées),
ce qui permet la **sidebar de review unique** pour tous les types de médias.

## 5. Stockage : filesystem → MinIO

- v1 : `DATA_PATH/storage` + `express.static` + wildcard `media.routes.js`.
- v2 : `StorageService` (S3 SDK), **URLs présignées** PUT (upload direct navigateur→MinIO,
  non-bloquant) et GET (serving). Aucun fichier sur le FS du serveur applicatif.
- Validation magic bytes appliquée à la **finalisation** (lecture en-tête depuis MinIO).
